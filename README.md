# bobOS - privacy-focused browser

bobOS is a web operating sistem built to be simple 
and not let anyone access your datas.
It doesn't require a login, no cookies needed.
The files you save are stored only in your pc and 
no one else can see them.
Currently it has really few features: a calculator,
a notes app and settings (you can choose 
between 3 differents layout for the OS).
Other features are coming soon, like a browser 
and an ai assistents, always built with bobOs philosophy!
